# 💰 Expense Tracker

A simple and efficient expense tracking application built with **PHP**, **MySQL**, and **Bootstrap** (running on XAMPP).  
This project helps users manage their daily expenses, categorize spending, and view reports in a clean, responsive interface.

---

## 🚀 Features
- Add, edit, and delete expenses
- Categorize expenses (e.g., food, transport, bills)
- View expense history in a table
- Generate summary reports
- Responsive design with Bootstrap
- User-friendly interface

---

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap (for responsive design and styling)
- XAMPP (local development environment)
